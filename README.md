# Portfolio - Red Car Theme 🏎️


## Features

✨ **Modern Design** - Clean, professional UI with red car theme
🎨 **Responsive** - Fully responsive design for all devices
🚀 **Performance** - Built with React and Vite for optimal performance
📱 **Mobile Friendly** - Works seamlessly on all screen sizes
🎯 **Interactive** - Smooth animations and transitions
📧 **Contact Form** - Integrated contact form for inquiries
🔗 **Social Links** - Quick links to LinkedIn, GitHub, and more

## Sections

- **Hero** - Eye-catching introduction with animated car
- **About** - Professional background and education
- **Experience** - Career timeline with key achievements
- **Skills** - Technical skills organized by category
- **Projects** - Featured projects with descriptions
- **Contact** - Contact information and message form
- **Footer** - Social links and copyright

## Tech Stack

- **React** - UI library
- **Vite** - Build tool
- **CSS3** - Styling with animations
- **React Icons** - Icon library
- **JavaScript ES6+** - Modern JavaScript


## Customization

### Colors
The red car theme uses:
- Primary Red: `#d32f2f`
- Light Red: `#ff6b6b`
- Dark Background: `#0f0f0f` - `#2d2d2d`

### Content
Edit the component files in `src/components/` to update:
- `Hero.jsx` - Hero section content
- `About.jsx` - About section
- `Experience.jsx` - Work experience
- `Skills.jsx` - Technical skills
- `Projects.jsx` - Featured projects
- `Contact.jsx` - Contact information

### Styling
CSS files for each component are located in `src/components/`
Global styles are in `src/index.css` and `src/App.css`
